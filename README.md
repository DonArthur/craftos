# CraftOS

CraftOS is a modern project management application built with React, Spring Boot, and PostgreSQL.

Its goal is simple:

Help developers organize projects, learning, and daily work through a clean, offline-capable experience.

## Features

- Project Management
- Task Management
- Dashboard
- Offline Support (planned)
- Progressive Web App (planned)

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Zustand
- TanStack Query

### Backend

- Spring Boot
- PostgreSQL
- JWT Authentication

### Infrastructure

- Docker
- Docker Compose

Currently under active development.
